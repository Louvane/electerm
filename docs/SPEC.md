# ANCHOR 锚点终端 — 设计规格

日期:2026-08-24
状态:已评审(交互规格经用户逐项确认,视觉/交互以 `~/projects/ssh-ui-demo/index.html` 原型为基准)

## 1. 目标

自用 SSH 客户端:FinalShell 的布局与交互 + 跳板机链 + 无回传 + 可完全自主定制。
基于 electerm v5.3.0 后端(主进程),**全新重写渲染层**(React + antd)。

## 2. 架构边界(已确认:方案 A)

```
┌─ 渲染层(全部重写)──────────────┐   ┌─ 主进程(原样保留)─────────┐
│ React 18 + antd + manate store  │◄──►│ session-ssh(跳板链/认证)   │
│ 布局:左遥测栏/标签/快速连接/     │ws+ │ sftp/transfer(传输队列)    │
│       管理器/表单/终端/监控      │worker│ bookmark-group(分组实体) │
└─────────────────────────────────┘   └────────────────────────────────┘
```

- 保留:`src/app/**`、`src/client/{common,store,lib,preload}/**`、worker、升级/同步/认证等服务
- 重写:`src/client/components/**` 视图组件(绞杀者模式,从 `layout/layout.jsx` 切入)
- 包名 `anchor`(userData 目录隔离,不与官方 electerm 冲突)

## 4. 交互规格(已确认)

- **连接** ≤2 步:快速连接页双击行 / 管理器双击主机;会话建立后主页标签自动关闭
- **主机三入口**:快速连接(历史扁平列表,可清空)/ 连接管理器(树+CRUD)/ 表单抽屉
- **表单**:四段折叠(基本/认证/跳板链/高级);新建无默认值;分组=下拉选(不可手填);编辑全量预填
- **跳板链**:列表引用已有主机(下拉选择),序号+上下移序;目标机固定最后
- **文件夹**:独立分组实体(对应 electerm bookmark-group);内联新建/重命名(Enter/Esc);非空删除需确认(子项上移);空组显示占位
- **主机删除**:不弹确认,toast 5 秒可撤销
- **右键菜单**:文件夹 6 项(新建主机预填分组/新建子文件夹/重命名/移动到…/删除);主机 5 项(连接/编辑/复制/移动到…/删除);点击即收起菜单
- **键盘**:↑↓ 选择,→/← 展开/折叠,Enter 连接,F2 重命名,Del 删除;Esc 按层级关闭(内联编辑>菜单>抽屉>管理器)
- **搜索**:过滤+自动展开+命中高亮

## 5. 主题系统

- 应用双主题:`dark` 琥珀磷光仪表台(默认)/ `light` 冷灰蓝纸面+焦琥珀;token 驱动;跟随系统+持久化
- 终端主题独立于应用主题(5 预设:琥珀磷光/磷光绿/Dracula/Solarized Dark/纸白),独立持久化
- 质量底线:焦点可见、prefers-reduced-motion、对比度 ≥4.5:1

## 6. 监控

复用会话 exec 通道轮询 `/proc/stat|meminfo|net/dev`(2s,60 点环形缓冲),
CPU/内存/网络三路曲线;仅 ssh 类型标签显示;解析容错(非 Linux 静默重试)。

## 7. 非目标(v1 不做)

拖拽排序/多选批量/SFTP 面板(v2)/云同步 UI/AI/RDP-VNC 入口/多窗口
